Installing (beta build)
  1. Run the downloaded .exe. Windows SmartScreen may show "Windows protected your PC" — this is expected for a new beta build. Click More info, then Run anyway.
  2. Follow the installer prompts. AltTracker installs to your user folder — no admin rights needed.
  3. On first launch, use File → Open to load your data file, or start fresh.
